# Z-Image LoRA Adapters

Place Z-Image Turbo compatible LoRA files (.safetensors) in this directory.

## Naming Convention

Use descriptive filenames without spaces:

- `style_anime.safetensors`
- `character_portrait.safetensors`
- `realistic_photo.safetensors`

The filename (without extension) is used as the `lora_name` in API requests.
