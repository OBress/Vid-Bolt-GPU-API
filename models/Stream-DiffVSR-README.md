# Stream-DiffVSR Video Upscaling

Stream-DiffVSR provides diffusion-based video super-resolution for automatically upscaling 720p videos generated by LTX-2 to 1080p.

## Overview

Stream-DiffVSR is a low-latency, streamable video super-resolution model that:

- Uses **Auto-regressive Temporal Guidance (ARTG)** for motion-aligned upscaling
- Employs a **4-step distilled denoiser** for real-time performance
- Includes a **temporal VAE decoder** for enhanced temporal coherence
- Operates **causally** (only uses past frames) for efficient streaming

### Performance

| Metric                | Value               |
| --------------------- | ------------------- |
| Latency per frame     | ~0.328s on RTX 4090 |
| Total time (4s video) | ~5-10 seconds       |
| VRAM usage            | ~8GB additional     |
| Input resolution      | 720p (1280x720)     |
| Output resolution     | 1080p (1920x1080)   |

## Model Download

**Models are automatically downloaded from HuggingFace on first use.** No manual download required.

- **Model ID:** `Jamichsu/Stream-DiffVSR`
- **Repository:** https://huggingface.co/Jamichsu/Stream-DiffVSR

### Manual Download (Optional)

If you prefer to pre-download models or are behind a firewall:

```bash
# Using huggingface-cli (recommended)
pip install huggingface-hub
huggingface-cli download Jamichsu/Stream-DiffVSR --local-dir models/stream-diffvsr

# Or using git lfs
git lfs install
git clone https://huggingface.co/Jamichsu/Stream-DiffVSR models/stream-diffvsr
```

## Configuration

Add these environment variables to your `.env` file:

```bash
# Enable/disable automatic upscaling (default: true)
STREAM_DIFFVSR_ENABLED=true

# HuggingFace model ID (auto-downloads on first use)
STREAM_DIFFVSR_MODEL_ID=Jamichsu/Stream-DiffVSR

# Device for inference
STREAM_DIFFVSR_DEVICE=cuda

# Number of denoising steps (4 is optimal for distilled model)
STREAM_DIFFVSR_NUM_INFERENCE_STEPS=4

# Output resolution (16:9 aspect ratio)
STREAM_DIFFVSR_OUTPUT_HEIGHT=1080
STREAM_DIFFVSR_OUTPUT_WIDTH=1920

# Testing mode (skip model loading)
STREAM_DIFFVSR_DRY_RUN=false

# TensorRT acceleration (experimental - may reduce quality)
STREAM_DIFFVSR_ENABLE_TENSORRT=false
```

## How It Works

When a video is generated by LTX-2:

1. **Frame Extraction**: The 720p video is decoded into individual frames
2. **Optical Flow**: RAFT computes motion between consecutive frames
3. **Upscaling**: Each frame is upscaled using the diffusion model with temporal guidance
4. **Reconstruction**: Frames are re-encoded to 1080p video with preserved audio

```
LTX-2 (720p) → Extract Frames → Stream-DiffVSR → Reconstruct (1080p) → Upload
```

## Disabling Upscaling

To disable upscaling (return 720p videos directly):

```bash
STREAM_DIFFVSR_ENABLED=false
```

## Troubleshooting

### Out of Memory (OOM)

If you encounter VRAM issues:

1. **Enable sequential offloading in LTX-2:**

   ```bash
   LTX2_FP8_ENABLED=true  # Reduces LTX-2 VRAM usage
   ```

2. **Disable upscaling temporarily:**
   ```bash
   STREAM_DIFFVSR_ENABLED=false
   ```

### Models Not Loading

Ensure the Stream-DiffVSR repository is cloned in the project root:

```bash
ls Stream-DiffVSR/
# Should show: inference.py, pipeline/, temporal_autoencoder/, etc.
```

### Dry Run Testing

To test the workflow without loading models:

```bash
STREAM_DIFFVSR_DRY_RUN=true
```

This passes through videos unchanged while simulating the upscaling process.
